LEDGER - APPOINTMENT DESK

Files in this folder:
  index.html    The complete app (calendar, multi-day booking, place/room, PDF report)
  netlify.toml  Netlify settings
  README.txt    These instructions

How to publish on Netlify:
  1. Go to https://app.netlify.com/drop
  2. Drag this whole folder onto the page.
  3. Netlify gives you a live link right away.

Notes:
  - Bookings are saved in each visitor's own browser.
  - The page loads fonts and the PDF tool from the internet.
